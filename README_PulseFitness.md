
# Pulse Fitness Analytics Platform 🏋️‍♂️📊

This project showcases a full-scale analytics solution for Pulse Fitness — a multi-location gym offering memberships, personal training, and group classes. It simulates how data is modeled, managed, and analyzed to derive actionable business insights using SQL and database best practices.

---

## 📌 Project Overview

**Objective:**  
To design and implement a data-driven analytics platform for a fitness center to support operational decision-making, improve member engagement, and increase revenue retention.

---

## 🛠️ Tools & Technologies
- **MySQL** for database design and query execution
- **Chen Notation** for ERD modeling
- **Using GenAI** for dummy data generation
- **MS Word** for business report
- **PowerPoint** for executive summary

---

## 🧱 Database Architecture

- Designed a **relational schema** with 9 entities:
  - Member, Trainer, MembershipType, GymLocation, FitnessClass, ClassEnrollment, PersonalTrainingSession, FacilityVisit, Payment
- Resolved many-to-many relationships via **associative entities**
- Followed 3NF principles and implemented referential integrity via foreign keys
